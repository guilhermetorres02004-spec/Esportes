# Checklist por etapa

Rode este checklist inteiro em cada etapa. Não pule itens porque a etapa "parece simples".

## Antes

- [ ] Esta é a única etapa "em andamento"?
- [ ] Reli a descrição da etapa e o requisito que ela atende?
- [ ] Todas as dependências estão concluídas e verificadas?
- [ ] Tudo o que a etapa usa (arquivo, função, API, comando) está no quadro de fatos?
- [ ] Reli agora o trecho exato que vou tocar (não confiei em leitura antiga)?
- [ ] Se a etapa é destrutiva ou irreversível, o usuário confirmou?

## Durante

- [ ] Estou fazendo só o que a etapa descreve?
- [ ] Segui as convenções do projeto (nomes, estrutura, tratamento de erro, estilo)?
- [ ] Não "aproveitei" para arrumar outra coisa? (se notei algo, anotei em "Fora do escopo")

## Depois

- [ ] Rodei a verificação definida e li a saída real?
- [ ] O resultado bate com o "Pronto quando"?
- [ ] Registrei a evidência em uma linha?
- [ ] Marquei como concluída só depois da verificação?
- [ ] Algo descoberto muda o plano? Se sim, parei e atualizei o plano antes de seguir.

## A cada 5 etapas (checkpoint)

- [ ] Reli o pedido original e o contrato de escopo.
- [ ] Tudo feito até agora aponta para algum requisito.
- [ ] Nenhuma suposição foi usada como se fosse fato.
- [ ] Atualizei o resumo de estado (concluídas / em andamento / pendentes / fatos-chave).
