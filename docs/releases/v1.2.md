# Versão 1.2

- Páginas de 22 modalidades migradas para React, com endereços sem `.html` e compatibilidade com links antigos.
- Escola de Esportes com carrossel automático, navegação lateral e links para as páginas específicas.
- Página Esporte nas Regionais ligada ao card Núcleos: dez regionais, filtros combináveis, 30 equipamentos e 20 fotografias reais.
- API pública do catálogo regional e edição restrita à sessão administrativa, com validação e persistência.
- Viva o Esporte com até cinco fotos oficiais alternadas a cada nove segundos, créditos e overlay azul.
- Integração do VLibras, controles de tamanho de fonte e contraste, ajustes no cabeçalho, rodapé e cards.
- Backend atualizado para Java 25 LTS e Spring Boot 3.5.16.

Validação: build de produção aprovado, 96 testes do frontend e 78 testes do backend aprovados.

Limitações registradas: mapa territorial das regionais depende de GeoJSON oficial acessível; dados não confirmados permanecem sinalizados. Conferência visual completa e execução do Nginx/Docker ainda pendentes.

Publicação do portal existente. Piloto antigo, pacotes locais desse piloto, configurações da IDE e hooks locais de modernização não fazem parte desta versão.
